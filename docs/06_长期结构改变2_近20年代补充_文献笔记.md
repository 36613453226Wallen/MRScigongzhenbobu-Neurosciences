## 中文文献 1（相同观点）

**出处**  
张建国, 毛晓飞, 陈艾彬, 蔡文鹏, 邓文曦, 李自强, 董薇. 海军某部官兵兴奋易感性与心理健康状态的关系：心理弹性和应对倾向的链式中介作用. 《海军军医大学学报》（原《第二军医大学学报》）. 2024;45(2):227–232.  
**来源标注：**【Cursor网搜】图二只给了王丽杰 2011 的论点卡片，没有点名本篇。选这篇是因为它把“过滤器 + 消极应对”做到了更大、更晚的军人样本上。  
**超链接：** [HTML 全文](https://html.rhhz.net/dejydxxb/html/2024/2/20230052.htm) · [期刊摘要页](https://xuebao.smmu.edu.cn/ajsmmu/article/abstract/20230052) · [DOI 10.16781/j.CN31-2187/R.20230052](https://doi.org/10.16781/j.CN31-2187/R.20230052)  
单位：海军军医大学心理系海军航空及特种心理学教研室。  
类型：海军官兵横断面问卷 + 结构方程模型。  
与图二：军人；类特质敏感是过滤器；应对倾向偏消极时心理健康更差。本篇**没有 MRI**。

**简短数据**  
- 发放 1 870 份，有效 1 865 份（99.7%）。工具：SRQ-20、CD-RISC、HSPS-10、简易应对方式问卷（SCSQ）。  
- SRQ-20 得分中位数 1（0，5）；≥ 7 分阳性 395/1 865（21.2%）。项目上最突出的是易疲劳 39.7%、睡眠差 34.3%、很难做决定 23.1%。  
- 相关：心理健康状态（分高=更差）与兴奋易感性 r = 0.34，与心理弹性 r = -0.46，与应对倾向 r = -0.33（应对倾向 = 积极应对标准分 − 消极应对标准分；越高越偏积极）。  
- 多元回归总解释率 30.1%（F = 201.96，P < 0.01）。  
- Bootstrap 中介：兴奋易感性 → 心理健康的直接效应占 58.9%；经心理弹性 22.2%；经应对倾向 14.8%；心理弹性 → 应对倾向的链式路径 4.0%；总间接效应 41.1%。

**四点体现分析**  
1. **过滤器还在：** 兴奋易感性是感觉加工敏感性里偏“容易被压力淹没”的一端，和神经质、特质焦虑走得很近。同样在海军训练环境里，高敏感者心理健康更差——这是图二“特质焦虑是过滤器”的同构，只是量表换成了 HSPS-10。  
2. **行事层面看见的仍是回避式适应：** 作者写明，兴奋易感性高的官兵更倾向消极应对；心理弹性越差，越愿意采用“更简单、更节省心理资源”的消极策略。这就是图二红线里的积极应对下降、消极应对上升。  
3. **复杂认知没有做作业测验，但症状已经指向负荷过高：** “很难做决定”进入前三主诉，疲劳和睡眠差并列。这是复杂作业变差的临床近邻，不是 Stroop / n-back 那种实验室证据。  
4. **缺结构一环：** 能补图二的行为链，补不了海马。所以它证明的是“不灵活适应策略会在军人群体里稳定复现”，而不是“策略与萎缩同批出现”。

**主要结论（论点）**  
在当代海军样本里，类特质的高兴奋易感性仍能筛出心理更差、应对更消极的人；长期军事环境中的不灵活适应，不必等 MRI 也能在行事问卷上被测到。

## 中文文献 2（不同情况的不同表现）

**出处**  
杨云芳, 商莹莹, 佘东立, 韩琳. 职业倦怠护士大脑形态学结构改变的初步探索. 《国际精神病学杂志》. 2023;50(1):142–145.  
**来源标注：**【Cursor网搜】图二未点名本篇。选这篇是因为同属职业慢性应激 + 结构 MRI，但解剖落点与王丽杰 2011 不同。  
**超链接：** [期刊条目](https://js.dnzh.org/magazine/contriution/12700) · [PDF](https://js.dnzh.org/FileUpload/PdfFile/20230323151835.pdf)  
单位：兰州大学护理相关团队（学位论文同源工作亦见兰州大学机构库）。  
类型：护士职业倦怠 VBM。  
与图二：有长期结构改变，但**不是双侧海马萎缩**，也没有报告复杂认知 / 应对方式。

**简短数据**  
- 职业倦怠护士 30 人，匹配无倦怠护士 29 人；静息 3D-T1，CAT12 / SPM12 做灰质体积 VBM。  
- 倦怠组灰质**增大**：左侧眶部额上回、左侧眶部额中回、右侧额中回。  
- 倦怠组灰质**减小**：右侧小脑 1 区、2 区、8 区（GRF 校正，单个体素 P < 0.001，校正后 P < 0.05）。  
- 改变脑区与护士 MBI 各维度评分均无显著相关（P > 0.05）。  
- 摘要未报告海马、杏仁核或尾状核的组间差异。

**四点体现分析**  
1. **职业现场确实还能看到形态学差**，这一点与图二“实验室 CA3 故事可以搬到真人职业场景”同向。  
2. **落点换了：** 王丽杰是海马萎缩；这里是眶额 / 额中回体积增加 + 小脑减小。增大既可能是代偿性增生，也可能是方法学噪声，作者自己也只写成“萎缩或增生”。  
3. **结构与主观倦怠脱钩：** 体积变了，却和 MBI 分对不上。图二的力量在于海马—复杂认知—消极应对绑在同一批人身上；本篇把这条绑带解开了。  
4. **样本小、横断面、无认知作业**，所以它适合当“不同表现”的对照，不适合用来否定军人海马发现。

**主要结论（论点）**  
中国职业倦怠护士的 MRI 改变可以出现在额眶和小脑，而不必复制军人样本里的双侧海马萎缩；长期结构改变的解剖配方随职业、症状维度和成像方法而分叉。

## 外文文献 1（相同观点）

**出处**  
Abe K, Tei S, Takahashi H, Fujino J. Structural brain correlates of burnout severity in medical professionals: A voxel-based morphometric study. *Neuroscience Letters*. 2022;772:136484.  
**来源标注：**【Cursor网搜】图二未点名本篇。选这篇是因为职业慢性应激下，**结构减配与不灵活的人际适应（去人格化）同向出现**。  
**超链接：** [DOI 10.1016/j.neulet.2022.136484](https://doi.org/10.1016/j.neulet.2022.136484) · [PMC 9758014](https://pmc.ncbi.nlm.nih.gov/articles/PMC9758014/) · [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S0304394022000416)  
单位：东京医科齿科大学 / 昭和大学等。  
类型：在职护士结构 MRI（VBM）与倦怠维度相关。  
与图二：职业现场；控制回路灰质越小，去人格化越高——去人格化就是把人当物、情感关闭，属于行事上的保守 / 回避。

**简短数据**  
- 在职护士 43 人（女 32），结构 MRI + 情绪耗竭、去人格化自评。  
- 情绪耗竭越高，双侧腹内侧前额叶（vmPFC）和左侧岛叶灰质体积越小。  
- 去人格化越高，左侧 vmPFC 和左侧丘脑灰质体积越小。  
- 后续综述引用本篇时补充：海马灰质与情绪耗竭 / 去人格化无显著关联——结构打击在前额叶—岛叶—丘脑，不在海马。

**四点体现分析**  
1. **又一次把慢性职业应激写成可见的灰质差**，不必是战争或童年虐待。  
2. **不灵活发生在人际策略上：** 去人格化不是认知测验分数，而是对病人 / 同事关掉共情。这和图二“环境适应往保守、回避走”是同一类行事，只是场景从军事训练换成病房。  
3. **vmPFC 是再评估和情绪下调的瓶颈**；它变小，和 Savic 系列里前额叶变薄、下调负性情绪变差是一条路上的不同尺子。  
4. **海马不是这篇的主角**，所以它支持的是“结构改变 + 不灵活策略同批出现”，不是“一定是海马萎缩”。

**主要结论（论点）**  
在职业倦怠的护士身上，腹内侧前额叶—岛叶—丘脑灰质越小，情绪耗竭和去人格化越重；长期结构减配与不灵活的适应策略可以在没有军事训练、也不依赖海马萎缩的人群里同时出现。

## 外文文献 2（不同情况的不同表现）

**出处**  
Chmiel J, Kurpas D. Burnout and the Brain—A Mechanistic Review of Magnetic Resonance Imaging (MRI) Studies. *International Journal of Molecular Sciences*. 2025;26(17):8379.  
**来源标注：**【Cursor网搜】图二未点名本篇。选这篇是目前能检索到的、专门讨论职业倦怠 MRI 机制、且把**海马“经常不被打到”**写成与 PTSD / 抑郁对照的较新综述（检索截止 2025-05，发表 2025-08-28）。  
**超链接：** [DOI 10.3390/ijms26178379](https://doi.org/10.3390/ijms26178379) · [MDPI 页](https://www.mdpi.com/1422-0067/26/17/8379) · [PMC 12429168](https://pmc.ncbi.nlm.nih.gov/articles/PMC12429168/)  
单位：什切青神经反馈与 tDCS 研究所、弗罗茨瓦夫医科大学。  
类型：按 PRISMA 原则改编的机制性综述（17 项临床 MRI，约 1 365 人扫描，其中倦怠 / 耗竭约 880，对照约 470）。  
与图二：承认前额叶、纹状体、杏仁核的长期结构改变，但认为**职业倦怠并不稳定复制海马萎缩**。

**简短数据**  
- 检索 2000-01 至 2025-05，纳入 17 项英文、有 MRI 结局、有验证过的倦怠诊断的临床研究。  
- 结构形态学（8/17）：较一致的是杏仁核增大（以女性为著），以及腹内侧前额叶、尾状核—壳核灰质减少。  
- 作者对测过海马的研究的归纳是：全海马或 CA1–CA4 / 齿状回亚区与匹配对照无差异；护士 VBM（即上面 Abe 2022）里海马也不随耗竭 / 去人格化变；办公室职业应激的手工体积测量里尾状核 / 壳核变小但海马与对照难分；Savic 随访里尾状核和前额叶可部分回到对照，海马两个时间点都稳定。  
- 功能像（9/17）：额皮质过度激活、杏仁核—ACC 耦合减弱、富俱乐部网络碎片化。  
- 两项纵向和若干干预亚研究：正念、运动、CBT、神经反馈或 rTMS 后，皮层变薄和边缘高反应可部分逆转。

**四点体现分析**  
1. **相同的那一半：** 职业慢性应激仍留下 MRI 可见的前额叶减配、纹状体减配、女性杏仁核超配——这和图二“长期结构改变是真的”不打架。  
2. **不同的那一半：** 图二把军人高特质焦虑亚组的海马萎缩写成核心结构事实；本综述把职业倦怠的海马写成“结构上相对硬朗”，用来和 PTSD、抑郁症划界。应激类型（军事高强度训练 vs 职业耗竭）、筛法（SCL-90 焦虑因子 ≥ 3 vs MBI）和性别构成都可能把海马从“主灶”变成“不显著”。  
3. **不灵活不一定要海马先塌：** 综述强调执行过度代偿和网络效率下降；复杂认知变差可以先是功能连接和纹状体的事。  
4. **可逆性再次出现：** 压力或干预下来之后，前额叶 / 尾状核比杏仁核更容易往对照靠——这和 2017/2018 年 Savic 结构随访同向，说明“改完就锁死”不是默认结局。

**主要结论（论点）**  
2015 年以后的职业倦怠 MRI 证据支持“长期结构改变”，但配方更常是前额叶—纹状体—杏仁核，而不是王丽杰 2011 军人亚组里的双侧海马萎缩；海马是否缩小，取决于应激种类、人群和筛法，不能当成所有慢性应激的统一结局。

## 四篇合读后的总论点

1. **图二的行事句子在 2024 年的军人样本里仍然成立：** 类特质敏感者更倾向消极应对，心理健康更差。  
2. **图二的结构句子不能原样推广到所有职业应激：** 护士 VBM 和 2025 年综述都显示，慢性职业负荷可以改前额叶、小脑或纹状体，而海马保持不显著。  
3. **“结构改变 + 不灵活适应同批出现”仍然是一条有用的总纲**，只是结构落点（海马 / vmPFC / 尾状核 / 小脑）和“不灵活”的尺子（消极应对 / 去人格化 / 心理疲劳）会换。  
4. **越晚的文献越提醒方法边界：** 筛查切点、MBI 阈值、性别比和有没有对照，会决定你看见的是海马故事还是前额叶—纹状体故事。
