# 收录说明

本目录提供与 Savic 2020（*Cerebral Cortex* 职业耗竭谷氨酸研究）相关的问答与文献笔记。

## 建议先读哪一份

若只保留一套文件，请用完整收录（问答 + 适应分析 + 两份文献笔记）：

- `收录/慢性应激大脑改变与睾酮保护_完整收录.pdf`
- `收录/慢性应激大脑改变与睾酮保护_完整收录.docx`

主题文档（题目 3.1 / 3.2）各有 pdf 与 docx：

- `收录/长期结构改变_文献笔记.pdf` / `.docx`  
  境外 4 篇 + 大陆境内 2 篇；每篇含出处、简短数据、四点体现分析、主要结论。
- `收录/睾酮保护原理_文献笔记.pdf` / `.docx`  
  体例同上。

Markdown 底稿在 `docs/00`–`docs/04`（`00` 为来源标注说明）。重新生成：`python3 scripts/build_docs.py`，再用 `scripts/html_to_pdf.sh` 将对应 html 打成 pdf。每条文献在正文中标【截图他源】或【Cursor网搜】，并带超链接。
